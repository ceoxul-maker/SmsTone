# 短信专属铃声 SmsTone 0.3.1 测试版

修复亮屏收到匹配短信后，声音已循环但没有及时可见的停止/打开短信入口；并补齐系统铃声选择的确认与返回操作。

## 更新内容

- 新增可授权的悬浮控制：强制提醒期间显示“停止提醒”“停止并打开短信”，停止后移除并恢复原闹钟音量。
- 强制提醒通知增加独立“停止并打开短信”；改进全屏权限未授权时的系统降级通知，前台通知立即显示，锁屏公开部分只显示通用提醒文字和操作，不显示组名。
- 首页增加悬浮授权提示与应急停止/打开短信按钮；权限设置增加悬浮窗和强制提醒通知类别入口。
- 系统铃声选择改为应用自己的列表，固定“返回”“取消”“试听所选”“确定”；只有点确定才返回新声音，取消/返回保留原声音。
- 最多6组、多号码匹配、个性音频、强制循环、振动、闪光等原功能保留。

## 升级后请设置一次

覆盖安装，不要先卸载，以保留规则和导入音频。打开首页的“设置悬浮停止按钮”，或进入“强制提醒权限与后台设置 → 悬浮停止按钮”，在系统中允许“显示在其他应用上层/悬浮窗”。这是本版新增的可选权限，只用于响铃期间显示操作按钮，不读取屏幕或短信正文。

锁屏全屏提醒仍需单独授权。部分安全系统页面可能隐藏悬浮窗；可以下拉展开强制提醒通知，或打开本应用首页停止。不能保证绕过所有厂商限制。

## 下载与验证

普通使用者下载 `SmsTone-0.3.1.apk`；源码、中文使用说明与 SHA256 校验文件随附。与已有发布版同一签名，可以保留设置覆盖升级。

Android 15 AOSP 模拟器验证：旧版在系统不展示常规弹出路径时复现无可见入口；新版悬浮两个按钮都可停止并恢复音量，“打开短信”进入默认短信应用；展开通知操作及锁屏全屏页可用。系统铃声取消、返回不改原选择，确定保存生效。尚待荣耀真机复测。
