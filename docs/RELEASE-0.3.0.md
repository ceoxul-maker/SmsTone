# 短信专属铃声 SmsTone 0.3.0 测试版

为重要短信设置专属提示音，同时保留手机默认短信应用。由 AI 编写，MIT 开源，无联网权限。

## 这一版包含

- 最多 6 组号码，每组支持多个完整来源号码。
- 系统铃声或本地音频，导入后保存在应用内。
- 可选最大闹钟音量循环提醒、振动和闪光，手动停止后恢复原音量。
- 首页独立“编辑”“试听”，编辑页“保存并试听”实际执行整套效果。
- 本地选择默认音频列表，支持类型及“本周”筛选；返回、取消不改变原音频。
- 点击普通提醒或停止强提醒后，使用系统默认短信应用查看消息。
- 中文使用介绍、隐私与权限说明、通用后台设置说明。

## 下载

普通用户选择 **SmsTone-0.3.0.apk**。`SHA256-0.3.0.txt` 用于完整性校验，`使用说明-0.3.0.txt` 可离线阅读。源码可下载本页 Source code 或附件源码包。

本次只发布 0.3.0。已安装同签名测试版可覆盖升级，请不要先卸载，以免清除规则与导入音频。

## 首次设置

允许接收短信、通知，再添加号码组并试听。音频库与闪光权限按需授予；在系统设置中允许后台运行，并按需授权锁屏全屏提醒。强提醒试听会实际最大音量循环，请准备手动停止。

业务代码仅使用新短信来源号码，不提取、展示、保存或上传短信正文，不读取历史短信；没有联网权限。正文仍在默认短信应用中查看。

**强制提醒不保证绕过完全勿扰、禁止闹钟、厂商后台拦截或强行停止。** 请在勿扰中允许闹钟，并用真实短信测试。振动和闪光效果以硬件、权限及系统限制为准。

支持 Android 8.0 及以上，仅 Android，无 iOS 版本。已完成 40 条纯 Java 边界测试和 Android 15 AOSP 模拟器验证，尚未完成各品牌真机兼容验证。详细介绍、权限和构建说明见仓库 README 与 docs。
